# Assessment Center
Eigenständige Datenbanktabellen, API /api/assessment und Gast-API /api/assessment-gast. Zugriff nur Polizeirat und Administrator; Ausbildungsleitung oder Ausbildungs-Einzelrechte allein reichen nicht. Bewerber werden mit RP-Namen unabhängig von der Personalakte erfasst. Vier-Augen-Korrektur wie im Theorieprüfungszentrum. Drei Vorlagentypen; keine realen Fragen oder Lösungswerte vorinstalliert.
## Einrichtung
Aktuelles verschlüsseltes IDV-Backup erstellen und herunterladen. Administrator öffnet Personal & Dienst → Assessment Center → Nach Backup einrichten. Alternativ additive Migration scripts/mysql/2026-11-25-assessment.sql nach Backup einspielen. Import über Bearbeitungslink oder ID des jeweiligen Google-Forms-Formulars und berechtigtes Google-Konto. Punkte, Musterlösungen, Dauer und Bestehensgrenze fachlich prüfen und Version speichern. Google OAuth und Groq-Konfiguration werden als technische Dienste mit dem Prüfungszentrum geteilt; Prüfungsdaten und Berechtigungen bleiben getrennt.
